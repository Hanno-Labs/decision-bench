# Contributing

DecisionBench has four contribution paths:

- [add a model adapter](adding_a_model.md);
- [submit reviewed result records](submitting_results.md);
- [add a task](adding_a_task.md); or
- [define a benchmark release](adding_a_benchmark.md).

Runtime code and result records are reviewed independently so leaderboard data cannot be changed by
editing presentation code.
