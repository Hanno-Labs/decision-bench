# Contributing

DecisionBench has four first-class contribution paths:

- [Add a Model](adding_a_model.md) — make a new decision model compatible with the runner.
- [Submit Results](submitting_results.md) — publish reviewed scores for a compatible model.
- [Add a Task](adding_a_task.md) — contribute one dataset-backed decision problem.
- [Add a Benchmark](adding_a_benchmark.md) — curate tasks into a named evaluation for a domain
  or purpose.

Runtime code and result records are reviewed independently so leaderboard data cannot be changed by
editing presentation code.
